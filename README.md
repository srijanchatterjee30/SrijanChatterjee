# Srijan: In the making

A personal space taking shape. An eclipse opens into a glass signature and a continuous Möbius ribbon, with a scroll-driven infinity transition and a mirrored surface.

## Website

The entire experience lives in `index.html`: styles, geometry, shaders, and interactions are embedded. No runtime dependencies, external assets, or build step are required to serve it.

Open `index.html` directly, or preview it locally:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

The animation supports scrolling in both directions, pointer interaction, and system reduced-motion preferences. The final section links to [chatterjeesrijanofficial@gmail.com](mailto:chatterjeesrijanofficial@gmail.com).

## Publishing

GitHub Pages serves the root of the `main` branch. Updating `index.html` updates the website after the Pages build completes.
